# Skills used to write One More Day's copy

`copywriting/` and `copy-editing/` are copied unchanged from
[coreyhaines31/marketingskills](https://github.com/coreyhaines31/marketingskills)
under the MIT License (see `LICENSE-marketingskills`). Copyright (c) 2025 Corey Haines.

Before using them, read `.agents/product-marketing.md`: our voice guide. It overrides
the skills wherever they suggest sales tactics (urgency, pressure, social-proof numbers)
that don't belong in an app for people in recovery.

How we use them: write with `copywriting`, then run the Seven Sweeps from
`copy-editing` over every screen. All interface text lives in `src/copy/en.ts`.
